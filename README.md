# 🌐 CodeAlpha_LanguageTranslationTool

**CodeAlpha Artificial Intelligence Internship — Task 1: Language Translation Tool**

A simple AI-powered web app that translates text between languages, built with **Python + Streamlit**.

---

## ✨ Features

- 🖊️ Clean user interface to enter text
- 🌍 Choose source language (or auto-detect) and target language
- 🔁 Instant translation using `deep-translator` (Google Translate engine — free, no API key needed)
- 📋 One-click copy of the translated text
- 🔊 Optional text-to-speech playback of the translation

---

## 🛠️ Tech Stack

- Python 3.9+
- [Streamlit](https://streamlit.io/) — UI framework
- [deep-translator](https://pypi.org/project/deep-translator/) — translation engine
- [gTTS](https://pypi.org/project/gTTS/) — text-to-speech

---

## 🚀 How to Run Locally

1. **Clone the repository**
   ```bash
   git clone https://github.com/<your-username>/CodeAlpha_LanguageTranslationTool.git
   cd CodeAlpha_LanguageTranslationTool
   ```

2. **Install dependencies**
   ```bash
   pip install -r requirements.txt
   ```

3. **Run the app**
   ```bash
   streamlit run app.py
   ```

4. Open the local URL shown in the terminal (usually `http://localhost:8501`).

---

## 📸 How It Works

1. Select the source language (or leave as "auto" for automatic detection).
2. Select the target language.
3. Type or paste the text you want to translate.
4. Click **Translate**.
5. View the translated text, copy it, or listen to it using the audio player.
